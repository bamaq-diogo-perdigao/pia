Selecione, anote, recorte e salve. Sem uploads e sem e-mail.

A captura usa a sessão gráfica onde a PIA está rodando.

Como capturar

Arraste com o botão esquerdo para selecionar à mão livre. Segure Ctrl para selecionar um retângulo. O botão direito desenha; Ctrl+botão direito desenha retângulos. A roda muda a espessura. Delete desfaz a última anotação.

Enter ou Espaço captura a tela inteira. Escape cancela. Ctrl+roda amplia no cursor. Esquerdo sempre recorta; direito sempre anota. Pressione o outro botão para cancelar um gesto. O botão do meio copia a cor HTML do pixel.
